This repository contains the supplementary dataset associated with the following article:

Ahn, H., Yu, J., & Lee, C. (2026). A measurement protocol and multimodal UAV telemetry dataset for fault observability under real-flight and safety-constrained test conditions. Measurement, Article 122820. https://doi.org/10.1016/j.measurement.2026.122820

The dataset includes multimodal UAV telemetry logs, metadata, anomaly annotations, preprocessing files, and baseline scripts used in the study. It is provided to support the reproducibility of the published results and to facilitate future research on UAV fault observability, telemetry-based anomaly detection, and measurement-oriented benchmarking.

If you use this dataset in your research, please cite the above Measurement article as the primary reference, as it provides the complete methodology, experimental design, dataset construction protocol, and technical validation. Please also cite this Zenodo record to acknowledge the use of the dataset.
