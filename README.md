# AhnUAVFault: A Real-Flight Multimodal UAV Telemetry Dataset for Anomaly Detection in Aerial Monitoring and Sensing Operations

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.19455349.svg)](https://doi.org/10.5281/zenodo.19455349)
[![License: CC BY-NC 4.0](https://img.shields.io/badge/License-CC%20BY--NC%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc/4.0/)
[![Paper](https://img.shields.io/badge/Measurement-Elsevier-blue.svg)](https://doi.org/10.1016/j.measurement.2026.122820)

This repository contains the supplementary dataset, code, and resources associated with the following article:

> Hyojung Ahn, Jeongmin Yu, and Chaewon Lee, "A measurement protocol and multimodal UAV telemetry dataset for fault observability under real-flight and safety-constrained test conditions," *Measurement*, vol. 290, art. no. 122820, 2026. DOI: [10.1016/j.measurement.2026.122820](https://doi.org/10.1016/j.measurement.2026.122820)

The dataset includes multimodal UAV telemetry logs, metadata, anomaly annotations, preprocessing files, and baseline scripts used in the study. It is provided to support the reproducibility of the published results and to facilitate future research on UAV fault observability, telemetry-based anomaly detection, and measurement-oriented benchmarking.
